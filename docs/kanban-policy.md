# Kanban Policy – Parts Unlimited

## Команда
PUL-Web

## Назначение
Документ определяет порядок движения рабочих элементов
на Kanban-доске и критерии завершения этапов.

## Основные состояния

### New
Работа зарегистрирована, но еще не утверждена.

### Approved
Работа рассмотрена и допущена к выполнению.

### Committed
Разработка завершена, изменение подготовлено
к проверке качества.

### QA Doing
Проводится контроль качества.

### QA Done
Контроль качества успешно завершен.

**Definition of Done для QA:**

- [ ] Проведена проверка требований.
- [ ] Выполнены необходимые автоматические тесты.
- [ ] Все обязательные тесты проходят успешно.
- [ ] Не обнаружены блокирующие дефекты.
- [ ] Результаты проверки зафиксированы.

### Done
Работа соответствует критериям приемки
и может считаться завершенной.

## Ограничения WIP

QA Doing: 1 рабочий элемент.

Лимит используется для обнаружения перегрузки.
Превышение лимита требует внимания команды.

## Приоритеты

Стандартная работа выполняется в обычном порядке.

Ускоренная работа имеет повышенный приоритет
и требует отдельного рассмотрения командой.
