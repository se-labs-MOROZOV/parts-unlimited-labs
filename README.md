# Parts Unlimited

Учебный проект по дисциплине «Программная инженерия».

## О проекте

Parts Unlimited — демонстрационный интернет-магазин
автомобильных запчастей.

Проект используется для изучения командной разработки,
управления требованиями, планирования работ, контроля
версий и автоматизации CI/CD на платформе GitHub.

## Цели

- Освоить совместную работу с Git и GitHub.
- Научиться вести проектную документацию.
- Изучить Agile, Scrum и Kanban.
- Освоить планирование спринтов и поставок.
- Настроить автоматическую сборку и тестирование.
- Реализовать конвейеры CI/CD.

## Инструменты

- GitHub Repositories
- GitHub Wiki
- GitHub Issues
- GitHub Projects
- GitHub Actions

## Лабораторные работы

1. Создание организации и проекта.
2. Работа с Wiki.
3. Подготовка тестовых данных.
4. Гибкое планирование и Scrum.
5. Kanban и мониторинг.
6. Графики поставок.
7. Настройка сборочного агента.
8. Непрерывная интеграция.
9. Конвейеры CI/CD на YAML.
